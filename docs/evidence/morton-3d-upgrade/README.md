# 3D optimization study evidence

See `../../MORTON-3D-UPGRADE.md` for protocol and interpretation. Measurements
cover 19 sampled cases, not the complete campaign. Source hashes normalize CRLF
to LF; their keys record paths at measurement time, before the dimension folders.
Plans identify original inputs and hashes; large inputs are not bundled.
Deprecated baseline/candidate source copies and their scratch driver were removed
in the repository cleanup. Measurement records remain unchanged. The corresponding
remote experiment snapshot is described in the study document.
