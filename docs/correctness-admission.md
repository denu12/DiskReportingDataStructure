# Correctness admission

Every entry, including Morton, must pass ordinary workloads **and** the boundary/duplicate fixtures generated by `tools/experiment_integrity.py`. Fixtures cover closed-sphere ties, repeated coordinates, zero radius and both uint32 grid edges. Dynamic fixtures also delete and reinsert one occurrence of a duplicated point.

Synthetic campaigns check the smallest ordinary workload per suite. Imported and dimensional campaigns check the smallest ordinary workload per supported dimension, retaining all indexed points and up to 32 original queries. Each supported dimension also receives its own exact fixture. A timeout, crash or incorrect multiset excludes that entry; infrastructure errors prevent trustworthy admission.

The independent full-scan oracle compares sorted coordinate multisets. Successful total answer counts are also cross-checked across implementations and repetitions in every phase, including final measurements. Counts are compared to prior phases when case and query counts match. A disagreement blocks progression and marks all implicated current measurements; agreeing totals are only a necessary check, not proof of correctness.

Admission is an experiment stage, not a separate regression-test framework. Binary, input, policy and harness identities connect admission to timing. Passing these inputs does not prove universal correctness. Historical measurements remain unchanged and are not retroactively certified by the new gate. See the [protocol](EXPERIMENTS.md).
