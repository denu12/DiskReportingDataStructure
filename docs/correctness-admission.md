# Correctness admission

Admission uses ordinary workloads. Artificial boundary, duplicate, empty and collinear stress fixtures are not exclusion gates and are not generated by the current preparation tools.

Synthetic static and dynamic campaigns check the smallest ordinary workload in each suite. Imported campaigns check the smallest ordinary workload per supported dimension, retaining all indexed points and up to 32 original queries. Incorrect answers, crashes and timeouts on those ordinary workloads determine admission under the shared execution policy.

An independent full-scan oracle checks coordinate multisets. Manifest, binary, harness and policy identities connect admission to timing. Competitor search code is not repaired after a failure. See the [protocol](EXPERIMENTS.md) and [reporting contract](REPORTING.md).

Correctness admission is the first experiment stage, not a software regression-test suite. Passing sampled ordinary workloads is evidence, not a proof of universal correctness. Infrastructure failures block measurement; existing data and results remain private in `historical_data/`.
